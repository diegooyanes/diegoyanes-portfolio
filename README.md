# Diego Yanes Garcia — Portfolio

A simple one-page portfolio for COMP 281A, built with plain HTML and CSS. It has no framework, build step, tracking script, or external template.

## Preview locally

Open `index.html` in a browser. You can also start a local web server with `python -m http.server 8000` and visit `http://localhost:8000`.

In that command, `-m` tells Python to run its built-in `http.server` module, and `8000` is the local port number. The command does not publish the site or change any project files.

## Publish with GitHub Pages

1. Create a **public** repository named `diegooyanes.github.io` under the `diegooyanes` GitHub account.
2. Upload `index.html`, `styles.css`, and the `assets` folder to the repository root. Commit the files to `main`.
3. Open repository **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`. Save.
4. Once deployment finishes, visit `https://diegooyanes.github.io/`. Check the navigation, GitHub and LinkedIn links, email link, and résumé PDF from that public address.
5. Submit `https://diegooyanes.github.io/` and `https://github.com/diegooyanes/diegooyanes.github.io` on Canvas.

The public résumé copy excludes a personal phone number, as requested in the assignment. Before publishing, read the text once and make sure every skill and project is something you can discuss in an interview.
